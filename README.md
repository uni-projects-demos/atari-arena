# Atari Model Arena UI

Web UI for testing trained models against classic Atari game engines and, when supported, users.

## Requirements

The UI is standalone, but [atari-model-arena-api](https://github.com/uni-projects-demos/atari-web-arena-api/) is required for loading models and Atari gameplay.

## Install

```bash
npm install
```

## Dev

```bash
npm run dev
```

## Build

```bash
npm run build
```

```bash
npm run preview
```
